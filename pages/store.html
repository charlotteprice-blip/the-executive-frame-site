How eLearning follows the method— five module types

Every module
maps to the sequence.

eLearning is not generic content. Each module type teaches a specific moment of the framework, in the order the system actually uses it.

01

Understand the Tunnel

Purpose: Recognise what pressure does to the system.

Maps to: The Problem — Instability → Confusion → Powerlessness.

02

Centre

Purpose: Stabilise the system before interpretation.

Tools: State naming, regulation, breath, grounding, Stop + Hold.

03

Clarify

Purpose: Restore cognitive accuracy.

Tools: Fact vs story, cognitive restructuring, Now / Do / Later, Focus.

04

Choose

Purpose: Act deliberately.

Tools: Microsteps, values, behavioural activation, Take Action.

05

Integrate

Purpose: Build a personal operating system.

Tools: Personal plan, relapse prevention, practice tracking.

Why this Store exists— access mission

Effective tools
should not only be available inside appointments.

The Store exists to make the core Executive Frame™ tools accessible earlier, at lower cost, and without waiting for live support.

  • Accessibility — for people with limited time, geography, or capacity for live support.
  • Earlier intervention — tools available before crisis, not only after.
  • Scalable impact — the framework reaches more people without diluting the work.
  • Continuity of practice — support that returns when pressure rises again.
